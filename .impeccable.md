# Studio design principles

The operator workspace should prioritize actual work, evidence, next actions and exact website versions. Use clear navigation, readable typography, restrained color and useful imagery. Preserve keyboard/touch access, contrast, responsive reflow and reduced motion.

Customer website proposals should have distinctive business-specific art direction, accurate content and a clear conversion goal. Technical QA and human creative judgment remain separate. See docs/NORTH-STAR.md and docs/UX-PROTOTYPE.html for the current product proposal.
