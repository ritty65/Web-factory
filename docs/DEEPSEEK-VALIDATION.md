## Reproduce the fictional proof

```sh
npm ci
node scripts/install-studio-runtimes.mjs
FACTORY_BROWSER_EXECUTABLE=/usr/bin/chromium npm test
FACTORY_BROWSER_EXECUTABLE=/usr/bin/chromium node scripts/proof-studio-pilot.mjs
```

The proof uses its own temporary database and private output directory under ignored `.artifacts/`. It supplies no real account credentials and sends no provider/model requests. It processes three fictional source-checked businesses across three simulated schedule dates, routes code to the DeepSeek adapter and screenshot review to the OpenRouter adapter, renders/QA-checks actual static files, and verifies exact proposal ZIPs. Private proposal files are not committed. Only fictional UI captures and a labelled proof receipt may enter `docs/visuals/`.

The solid-color photo fixture checks the actual uploaded-image/vision/asset/provenance path. It is not a real customer image, evidence of an attractive design, or permission for an unrelated image.

## Outside prerequisites and unproven outcomes

- No real API key has been supplied for DeepSeek, OpenRouter/OpenAI, Google Places, Apollo or Firecrawl. Live authentication, required paid-plan features, current schemas/model behavior, account charges and useful coverage remain untested.
- The running cloud instance enforces a package-manager-only network policy. The saved unrestricted draft and optional key requirements have not been applied or published. Native browser download and provider/public-source access remain blocked independently of code tests.
- No real fixed 30-business cohort was collected or manually audited. No actual qualification yield, reachable contact, buying interest or customer conversion is claimed.
- No actual DeepSeek-generated proposal or actual model visual judgment was accepted. Fictional AI replies and browser QA do not establish creative quality.
- No VPS access was supplied. The installer, HTTPS/authentication, native browsers, actual timer, encrypted off-server backup and 72-hour outage/restart/restore exercise must be checked on the real Hostinger server.
- Source-use, licensing, retention and pricing confirmations are operator declarations. They are not provider-account audits or legal certifications. The $100 app allowance relies on those rate ceilings; use provider-side account limits too.

The live acceptance targets remain: at least 80% active/local/service discovery accuracy in the fixed cohort, five suitable opportunities, three actual proposals, two operator acceptances and 72 actual VPS hours including failure/recovery exercises. Publication, outreach, forms/booking backends and ongoing customer-site maintenance are separate work.
